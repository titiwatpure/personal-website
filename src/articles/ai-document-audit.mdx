# การตรวจสอบความไม่สอดคล้องของเอกสารด้วย AI

## ปัญหาที่พบ

การตรวจสอบเอกสาร Audit ในงานวิศวกรรมเป็นงานที่ใช้เวลานานและต้องอาศัยความละเอียดสูง เอกสารแต่ละฉบับอาจมีหลายสิบหน้า และต้องตรวจสอบความสอดคล้องกับมาตรฐานหลายข้อ

- การตรวจสอบแบบ Manual ใช้เวลา **3-5 วัน** ต่อชุดเอกสาร
- ความผิดพลาดจากมนุษย์สูง โดยเฉพาะเมื่อต้องตรวจสอบเอกสารจำนวนมาก
- ไม่สามารถตรวจสอบแบบ Real-time ได้

## แนวคิดในการแก้ปัญหา

การนำ AI มาช่วยตรวจสอบเอกสารสามารถลดเวลาได้อย่างมีนัยสำคัญ หลักการคือ:

1. **OCR (Optical Character Recognition)** — อ่านข้อความจากเอกสาร PDF หรือภาพถ่าย
2. **NLP (Natural Language Processing)** — วิเคราะห์ความหมายของข้อความ
3. **Rule-based Validation** — ตรวจสอบความสอดคล้องตามกฎที่กำหนด
4. **ML Classification** — จัดประเภทเอกสารและหาความผิดปกติ

## เทคโนโลยีที่ใช้

- **Python** — ภาษาหลักสำหรับพัฒนาระบบ
- **FastAPI** — Web framework สำหรับสร้าง API
- **PostgreSQL** — ฐานข้อมูลสำหรับเก็บผลลัพธ์
- **OCR (Tesseract)** — อ่านข้อความจากภาพ
- **NLP Libraries** — วิเคราะห์ข้อความภาษาไทย

## ผลลัพธ์

- ลดเวลาตรวจสอบจาก **3-5 วัน** เหลือ **2-3 ชั่วโมง**
- ความถูกต้องในการตรวจสอบเพิ่มขึ้น **95%**
- สามารถตรวจสอบเอกสารได้แบบ Real-time
- ระบบทำงานอัตโนมัติ 24/7
